# Proton documentation

Uses mdBook 0.4.52 with its default theme. Install the `mdbook` binary; no
MoonBit, Node.js, npm, plugins, or custom theme files are required.

## Write

Edit Markdown in `content/en/` and `content/zh/`. Keep both translations and
code examples aligned. Add chapters to each language's `SUMMARY.md` and use
`.md` links between articles. The language link at the top of each article
points to the corresponding generated HTML page.

Keep guides task-oriented: state prerequisites, name the files to change,
provide the smallest complete example, and explain the expected result.
Examples document Proton 0.2.11; verify them with published dependencies.

## Preview

From `website/`:

```sh
mdbook serve
```

Open http://localhost:3000/ for English. For a separate Chinese preview:

```sh
mdbook serve zh --port 3001
```

Each preview rebuilds its own language. To preview language links together,
start the English server and run `mdbook build zh`; the Chinese pages will be
available at http://localhost:3000/zh/. Rebuild Chinese after editing it or
after the English server rebuilds (the English build replaces `dist/`).

## Publish

```sh
mdbook build
mdbook build zh
```

The `documentation` workflow runs these commands and deploys `dist/` to GitHub
Pages on `main`. Select **GitHub Actions** as the repository's Pages source.
The site URL is https://moonbit-community.github.io/proton/.

Default theme assets are generated by mdBook and are not committed.
The default highlighter does not recognize MoonBit; those blocks remain plain
code. No highlighting plugin is installed. Update the
release title in both `book.toml` files when updating the documented release.
