# 应用国际化

[English](../../examples/56_i18n.html)

命令上下文、Chromium 与原生菜单共用启动语言环境。

[56_i18n](https://github.com/moonbit-community/proton/tree/25d77e6236420025ddf1ab04995c0c2a05bba9ed/examples/56_i18n) · 关键文件：[main.mbt](https://github.com/moonbit-community/proton/tree/25d77e6236420025ddf1ab04995c0c2a05bba9ed/examples/56_i18n/main.mbt), [app.html](https://github.com/moonbit-community/proton/tree/25d77e6236420025ddf1ab04995c0c2a05bba9ed/examples/56_i18n/app.html)

## 行为

应用选择 zh-CN，同时显示后端语言偏好、navigator.language 和 navigator.languages。

## 运行

需满足[运行环境要求](../installation.md)。在仓库根目录执行：

```sh
moon -C examples run 56_i18n --target native
```

## 限制与使用边界

Proton 传递语言环境，不翻译业务文案。此示例在 Windows 上省略原生菜单，不能由其他平台的表现推断其菜单一致性。
